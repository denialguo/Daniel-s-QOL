# Daniel's QOL

A collection of Chrome extensions I built and published to make everyday browsing less annoying.

**9 published extensions · 4,100+ weekly active users · 13,500+ installs**

## Extensions

| Extension | What it does | Source | Chrome Web Store |
| --- | --- | --- | --- |
| **Simple Auto Clicker** | Lightweight browser auto-clicker with follow-mouse, element-picker, coordinate, hotkey, and high-CPS modes. | [GitHub](https://github.com/denialguo/simple-auto-clicker) | [Install](https://chromewebstore.google.com/detail/simple-auto-clicker/emggejledlldffijahchmidkmapjidfi) |
| **Google Infinite Scroll** | Restores continuous scrolling to Google Search and automatically loads additional result pages. | [GitHub](https://github.com/denialguo/infinite-scroll) | [Install](https://chromewebstore.google.com/detail/google-infinite-scroll/pohbddcpalgkpoappjppcimepfkklbhh) |
| **Playlist Pro for YouTube** | Replaces YouTube's playlist viewer with multi-select, drag-and-drop reordering, bulk actions, and persistent saves through YouTube's internal API. | [GitHub](https://github.com/denialguo/YT-Playlist-Pro) | [Install](https://chromewebstore.google.com/detail/playlist-pro-for-youtube/pfpppmlfbknnnhabihbffcmajgbogkeb) |
| **Return Search Results** | Restores Google's result-count display directly on search pages. | [GitHub](https://github.com/denialguo/return-search-results) | [Install](https://chromewebstore.google.com/detail/return-search-results/cnbhbbkeobbddeggknbjomnjijbklbah) |
| **FullTitles for Docs** | Expands truncated Google Docs titles, adds hover tooltips, and lets users adjust title font size. | [GitHub](https://github.com/denialguo/fulltitles-for-docs) | [Install](https://chromewebstore.google.com/detail/fulltitles-for-docs/facibffpiceegpfmnpcbmmkakocodmcl) |
| **Keyboard Cleaner** | Opens a safe typing tab and disables most keyboard shortcuts so you can clean your keyboard without shutting down. | [GitHub](https://github.com/denialguo/keyboard-cleaner) | [Install](https://chromewebstore.google.com/detail/keyboard-cleaner/chbkmgjlbjajobmccbbobhbeinffmbph) |
| **Grass Auto Clicker** | A cozy browser auto-clicker with multiple targeting modes, custom speeds, and hotkeys. | [GitHub](https://github.com/denialguo/grass-auto-clicker) | [Install](https://chromewebstore.google.com/detail/grass-auto-clicker/gngheimbbpkgaoeiobjemnajlmjngika) |
